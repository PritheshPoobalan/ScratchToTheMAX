# Contributing

## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Add or improve documentation, code, tests, or examples.
4. Commit with a clear message (no emojis).
5. Open a pull request.

## Areas needing help

- BADD CPU RTL verification.
- Johnsan compiler backend.
- Kernel drivers and servers.
- Test coverage.

Please open an issue before starting large changes.

## Code style

Follow the existing indentation and naming conventions. Keep commits focused
on a single change.
